# Group assignment 1.5: Gaussian Soil

In this assignment, you will analyse the joint behaviour of three soil properties: unit weight, water content, and plasticity index. You will investigate their dependence structure, fit a multivariate Gaussian distribution, estimate joint probabilities using Monte Carlo simulation, and explore conditional Gaussian distributions.

You can preview the instructions of this assignment on https://mude.citg.tudelft.nl/workbook-2026/assignments/GA1.5/README.html. After the deadline, this link will include solutions. The preview without solutions will remain available here: https://mude.citg.tudelft.nl/workbook-2026/no_solutions/assignments/GA1.5/README.html. All files of an assignment can be downloaded as [`.zip`-file](https://mude.citg.tudelft.nl/workbook-2026/_custom_downloads/assignments/GA1.5/all_files_GA_1_5.zip) to your computer.

At 11:30, you'll have to close laptops and receive a set of questions to be solved as a group. These questions are based on what you did in the first three hours. You can make use of notes written in the first three hours, but you are not allowed to use any other resources like AI. At 12:30, you'll hand in your handwritten answers to the questions.

Before you can start this assignment, you should have read the relevant theory in the book and completed the Wednesday's workshop and programming assignment of this week.

In this assignment you’ll make exercises on the following topics:

- [Dependence between soil properties and multivariate Gaussian distributions](./Gaussian_Soil.ipynb)
- Covariance and correlation
- Joint probability estimation using Monte Carlo simulation
- Conditional Gaussian distributions
